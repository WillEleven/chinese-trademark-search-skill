# Natural Language Examples

The following examples are intended as reference for OpenClaw when using this Skill.

1. Search for trademarks registered under "TechBrand Inc." in China. Show me the first page.
2. Look up the trademark keyword "TechBrand" and tell me how many points the search will cost first.
3. Continue to the next page of the previous search results.
4. Open the details for trademark `tm_20260310_0001`. Let me know if it will cost any points first.
5. Export the 3 trademarks from the last search as a file.
6. I want to export 68 results. First calculate the estimated point cost, then let me decide whether to proceed.
7. Check how many points I have left and whether it's enough for another search.
8. Show me which premium modules I currently have enabled.
9. If I haven't bound my platform account yet, guide me through the binding process first. Don't run a search directly.
10. If I don't have enough points, just tell me to top up. Don't proceed with any billable action.
11. If the "Company Page / Client Page" module is not enabled, tell me the specific module name.
12. Look up the details for the "TechBrand Shield" trademark and give me a summary of its status, class, and validity period.
13. Search for trademarks related to "Global Innovation Corp." If there are too many results, show a summary of the first few.
14. Check whether export job `exp_20260310_0003` has completed.
15. Before searching, first confirm whether I'm bound and whether I still have any trial points.
16. Show me the binding instructions and trial points policy.
