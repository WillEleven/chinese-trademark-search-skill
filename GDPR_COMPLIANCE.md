# GDPR Compliance Notice / GDPR 合规声明

**Effective Date:** 2026-03-28
**Last Updated:** 2026-03-28

---

## English

This notice describes how the Chinese Trademark Search platform processes personal data of individuals in the European Economic Area (EEA), United Kingdom, and Switzerland in compliance with the General Data Protection Regulation (EU) 2016/679 ("GDPR") and the UK GDPR.

### 1. Data Controller

The data controller for personal data processed through the Global region (`zqaiip.com`) is the platform operator. For inquiries, contact:

**Data Protection Officer:** dpo@zqaiip.com

### 2. Legal Basis for Processing

The platform processes personal data on the following legal bases:

| Processing Activity | Legal Basis (GDPR Art.) |
|---|---|
| Account creation and authentication | Art. 6(1)(b) - Contractual necessity |
| Trademark search query execution | Art. 6(1)(b) - Contractual necessity |
| Query logging for audit and compliance | Art. 6(1)(f) - Legitimate interest |
| Billing and points management | Art. 6(1)(b) - Contractual necessity |
| Security monitoring and fraud prevention | Art. 6(1)(f) - Legitimate interest |
| Legal compliance (sanctions screening) | Art. 6(1)(c) - Legal obligation |

The primary legal basis is **contractual necessity** (Art. 6(1)(b)), as the platform operates as a B2B SaaS service and data processing is necessary for the performance of the service contract.

### 3. Categories of Personal Data

| Category | Examples |
|---|---|
| User identification | User ID, account email, username |
| Organization data | Organization name, billing entity |
| Query history | Search terms, query timestamps, result counts |
| Trademark data accessed | Trademark IDs viewed, detail pages accessed |
| Technical data | IP address, API key identifiers, user agent |
| Billing data | Points balance, transaction history |

### 4. Data Retention

| Data Category | Retention Period |
|---|---|
| Query logs | 12 months from query date |
| Account data | Duration of account + 12 months |
| Billing records | As required by applicable tax law (typically 7 years) |
| Security logs | 6 months |

After the applicable retention period, data is anonymized or securely deleted.

### 5. Data Subject Rights

Under the GDPR, data subjects have the following rights:

| Right | Description |
|---|---|
| **Access** (Art. 15) | Obtain a copy of your personal data and information about how it is processed |
| **Rectification** (Art. 16) | Correct inaccurate or incomplete personal data |
| **Erasure** (Art. 17) | Request deletion of your personal data ("right to be forgotten") |
| **Portability** (Art. 20) | Receive your data in a structured, machine-readable format |
| **Objection** (Art. 21) | Object to processing based on legitimate interests |
| **Restriction** (Art. 18) | Request restriction of processing under certain conditions |

To exercise any of these rights, contact: **privacy@zqaiip.com**

Requests will be responded to within 30 days. The platform may request identity verification before processing requests.

### 6. Cross-Border Data Transfers

Personal data of EEA users processed through the Global region is stored in **Hong Kong SAR**. As the European Commission has not issued an adequacy decision for Hong Kong, the platform relies on the following transfer mechanism:

- **Standard Contractual Clauses (SCCs)** as adopted by the European Commission (Commission Implementing Decision (EU) 2021/914), supplemented by a Transfer Impact Assessment (TIA).

Key safeguards include:
- Encryption of data in transit (TLS 1.2+) and at rest (AES-256)
- Access controls limiting data access to authorized personnel
- Regular security assessments
- Data processing agreements with all sub-processors

### 7. Data Processing Agreement (DPA)

A Data Processing Agreement compliant with GDPR Art. 28 is available upon request for enterprise and B2B customers. To request a DPA, contact: **legal@zqaiip.com**

### 8. Sub-Processors

A current list of sub-processors is available upon request. The platform will notify customers of any intended changes to sub-processors at least 30 days in advance.

### 9. Data Breach Notification

In the event of a personal data breach, the platform will:
- Notify the relevant supervisory authority within 72 hours (Art. 33)
- Notify affected data subjects without undue delay where the breach poses a high risk to their rights and freedoms (Art. 34)

### 10. Complaints

Data subjects have the right to lodge a complaint with a supervisory authority in their member state of residence or place of work.

## 中文

本声明描述了中国商标查询平台如何根据《通用数据保护条例》(EU) 2016/679（"GDPR"）和英国 GDPR，处理位于欧洲经济区（EEA）、英国和瑞士的个人数据。

### 1. 数据控制者

通过全球区域（`zqaiip.com`）处理的个人数据的数据控制者为平台运营方。如有疑问，请联系：

**数据保护官（DPO）：** dpo@zqaiip.com

### 2. 处理的法律依据

平台基于以下法律依据处理个人数据：

| 处理活动 | 法律依据（GDPR 条款） |
|---|---|
| 账户创建和身份验证 | 第 6(1)(b) 条 - 合同必要性 |
| 商标查询执行 | 第 6(1)(b) 条 - 合同必要性 |
| 查询日志（审计和合规） | 第 6(1)(f) 条 - 合法利益 |
| 计费和点数管理 | 第 6(1)(b) 条 - 合同必要性 |
| 安全监控和反欺诈 | 第 6(1)(f) 条 - 合法利益 |
| 法律合规（制裁筛查） | 第 6(1)(c) 条 - 法律义务 |

主要法律依据为**合同必要性**（第 6(1)(b) 条），因为平台作为 B2B SaaS 服务运营，数据处理对于履行服务合同是必要的。

### 3. 个人数据类别

| 类别 | 示例 |
|---|---|
| 用户识别信息 | 用户 ID、账户邮箱、用户名 |
| 组织数据 | 组织名称、计费主体 |
| 查询历史 | 检索词、查询时间戳、结果数量 |
| 访问的商标数据 | 查看的商标 ID、访问的详情页 |
| 技术数据 | IP 地址、API 密钥标识符、用户代理 |
| 计费数据 | 点数余额、交易记录 |

### 4. 数据保留

| 数据类别 | 保留期限 |
|---|---|
| 查询日志 | 自查询之日起 12 个月 |
| 账户数据 | 账户存续期 + 12 个月 |
| 计费记录 | 依据适用税法要求（通常为 7 年） |
| 安全日志 | 6 个月 |

适用保留期限届满后，数据将被匿名化或安全删除。

### 5. 数据主体权利

根据 GDPR，数据主体享有以下权利：

| 权利 | 说明 |
|---|---|
| **访问权**（第 15 条） | 获取个人数据副本及处理方式信息 |
| **更正权**（第 16 条） | 更正不准确或不完整的个人数据 |
| **删除权**（第 17 条） | 请求删除个人数据（"被遗忘权"） |
| **可携带权**（第 20 条） | 以结构化、机器可读格式接收数据 |
| **反对权**（第 21 条） | 反对基于合法利益的处理 |
| **限制处理权**（第 18 条） | 在特定条件下请求限制处理 |

如需行使上述任何权利，请联系：**privacy@zqaiip.com**

请求将在 30 天内回复。平台可能在处理请求前要求身份验证。

### 6. 跨境数据传输

EEA 用户通过全球区域处理的个人数据存储在**中国香港特别行政区**。由于欧盟委员会尚未对香港作出充分性认定，平台依赖以下传输机制：

- 欧盟委员会通过的**标准合同条款（SCCs）**（委员会实施决定 (EU) 2021/914），并辅以传输影响评估（TIA）。

关键保障措施包括：
- 传输中加密（TLS 1.2+）和静态加密（AES-256）
- 访问控制，仅限授权人员访问数据
- 定期安全评估
- 与所有子处理者签订数据处理协议

### 7. 数据处理协议（DPA）

符合 GDPR 第 28 条的数据处理协议可应企业和 B2B 客户的要求提供。如需申请 DPA，请联系：**legal@zqaiip.com**

### 8. 子处理者

当前子处理者列表可应请求提供。平台将在拟变更子处理者时提前至少 30 天通知客户。

### 9. 数据泄露通知

如发生个人数据泄露，平台将：
- 在 72 小时内通知相关监管机构（第 33 条）
- 当泄露对数据主体的权利和自由构成高风险时，不当延误地通知受影响的数据主体（第 34 条）

### 10. 投诉

数据主体有权向其居住地或工作地所在成员国的监管机构提出投诉。
